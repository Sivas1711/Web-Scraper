
Developed a simple web scraper that extracts information from a website

This project is a simple Python-based scraper that retrieves the latest world news headlines from CNN and fetches Wikipedia summaries based on user input.

 Features

- ✅ Scrapes top 3 headlines from [CNN World](https://edition.cnn.com/world)
- ✅ Fetches summary of any topic using the Wikipedia API
- ✅ Uses `requests`, `BeautifulSoup`, and `wikipedia` libraries
- ✅ Optional Selenium setup for future enhancements

 Requirements

- Python 3.10+
- Google Chrome (Installed)
- ChromeDriver (Matching your Chrome version)

 Install Dependencies

bash
pip install requests
pip install beautifulsoup4
pip install wikipedia
